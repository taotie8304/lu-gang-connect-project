## 部署步骤

### 快速部署（推荐）

```bash
# 1. 进入项目目录
cd lugang-ai

# 2. 运行环境检查
node packages/service/core/dataset/autoUpdate/check-env.js

# 3. 运行部署脚本
bash packages/service/core/dataset/autoUpdate/deploy.sh

# 4. 启动应用
pnpm dev  # 开发环境
# 或
docker-compose up -d  # 生产环境

# 5. 检查日志
docker logs -f lugang-ai | grep "自动更新"
```

## 监控建议

### 关键指标

1. **定时任务执行**
   - 执行频率: 每月1号凌晨2点
   - 执行时长: 记录每次执行时间
   - 成功率: 记录成功/失败次数

2. **集合处理**
   - 处理数量: 每次处理的集合数

3. **性能指标**
   - 页面爬取时间

## 已知限制

1. **定时任务时间固定**
   - 当前硬编码为每月1号凌晨2点
   - 未来可考虑支持自定义时间

2. **文件大小限制**
   - 最大 100MB
   - 超过限制会下载失败

3. **并发限制**
   - 每次最多处理 3 个集合
   - 避免资源耗尽

4. **网络依赖**
   - 需要访问外部网站
   - 可能受防火墙影响
