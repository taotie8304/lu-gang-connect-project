# 知识库自动更新功能 - 前端测试指南

## 测试前准备

1. 确保后端服务正常运行
2. 确保有一个测试用的知识库集合
3. 确保用户有集合的写权限

## 测试步骤

### 1. 访问自动更新配置页面

1. 登录系统
2. 进入知识库管理页面
3. 点击任意一个集合，进入集合详情页
4. 在集合详情页，点击"自动更新"按钮
5. 应该跳转到自动更新配置页面

**预期结果**：
- 页面正常加载
- 显示"启用自动更新"开关（默认关闭）
- 其他配置项隐藏

### 2. 启用自动更新

1. 点击"启用自动更新"开关
2. 应该显示配置表单

**预期结果**：
- 显示数据源 URL 输入框
- 显示文件格式选择器
- 显示检测策略配置
- 显示保存和立即更新按钮
- 显示更新历史区域

### 3. 测试识别功能

1. 在数据源 URL 输入框中输入：`https://data.gov.hk/tc-data/dataset/hk-fehd-food-food-premises-licences`
2. 点击"识别"按钮
3. 应该弹出识别结果弹窗

**预期结果**：
- 弹窗显示识别到的文件列表
- 文件按格式分组显示
- 可以点击文件选择

### 4. 配置自动更新

1. 选择文件格式（如 CSV）
2. 配置检测策略：
   - 勾选"检查更新时间"
   - 勾选"详情页检查"
3. 点击"保存"按钮

**预期结果**：
- 显示"更新成功"提示
- 配置已保存到数据库

### 5. 测试手动触发更新

1. 点击"立即更新"按钮
2. 等待更新完成

**预期结果**：
- 显示"已触发更新"提示
- 更新历史列表中新增一条记录

### 6. 查看更新历史

1. 滚动到页面底部
2. 查看更新历史列表

**预期结果**：
- 显示历史记录表格
- 包含更新时间、状态、文件名、消息
- 显示最后检查时间和最后更新时间

### 7. 测试禁用自动更新

1. 关闭"启用自动更新"开关
2. 点击"保存"按钮

**预期结果**：
- 配置表单隐藏
- 配置已保存

## 常见问题

### 1. 识别按钮无响应

**可能原因**：
- 数据源 URL 为空
- 网络连接问题
- 后端服务未启动

**解决方法**：
- 检查 URL 是否正确输入
- 检查浏览器控制台是否有错误
- 检查后端服务状态

### 2. 保存配置失败

**可能原因**：
- 用户没有写权限
- 后端服务异常
- 数据库连接问题

**解决方法**：
- 检查用户权限
- 查看后端日志
- 检查数据库连接

### 3. 手动触发更新失败

**可能原因**：
- 配置未保存
- 数据源 URL 无效
- 后端服务异常

**解决方法**：
- 先保存配置
- 检查 URL 是否可访问
- 查看后端日志

## 浏览器兼容性

- Chrome 90+
- Firefox 88+
- Safari 14+
- Edge 90+

## 性能测试

### 1. 页面加载时间

- 首次加载：< 2秒
- 配置加载：< 1秒
- 历史记录加载：< 1秒

### 2. 识别功能响应时间

- 简单页面：< 3秒
- 复杂页面：< 10秒

### 3. 手动触发更新响应时间

- 小文件（< 1MB）：< 30秒
- 大文件（> 10MB）：< 5分钟
