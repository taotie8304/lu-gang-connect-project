### 新增配置

在根目录 `package.json` 中添加了 `pnpm.overrides` 配置：

```json
{
  "pnpm": {
    "overrides": {
      "react": "18.3.1",
      "react-dom": "18.3.1"
    }
  }
}
```

**作用**: 强制所有依赖使用统一的 React 版本，避免版本冲突。

### 安全漏洞详情

#### axios CVE-2023-45857

**漏洞类型**: Server-Side Request Forgery (SSRF)  
**严重程度**: 中等 (CVSS 5.3)  
**影响版本**: < 1.13.5  
**修复版本**: 1.13.5+

**漏洞描述**:
- axios 在处理某些 URL 时存在 SSRF 漏洞
- 攻击者可能利用此漏洞访问内部网络资源
- 可能导致敏感信息泄露

**修复内容**:
- 改进 URL 解析和验证逻辑
- 增强对内部 IP 地址的检测
- 修复重定向处理中的安全问题

#### lodash 原型污染

**漏洞类型**: Prototype Pollution  
**严重程度**: 低 (CVSS 3.7)  
**影响版本**: < 4.17.23  
**修复版本**: 4.17.23+

**漏洞描述**:
- lodash 的某些函数存在原型污染漏洞
- 攻击者可能通过特制输入修改对象原型
- 可能导致应用逻辑错误或安全问题

**修复内容**:
- 修复 `merge`、`mergeWith` 等函数的原型污染问题
- 增强对 `__proto__` 等特殊属性的检查
- 改进深度合并逻辑
