## 三、反爬降级与空结果处理（真实 403 验证）

连续快速请求后，DuckDuckGo 的 html / lite 两个端点均对本机返回 **HTTP 403**（需求文档第 6.7、
踩坑 #9 预警的数据中心/高频反爬）。插件行为：

- 主接口 403 → 被捕获并静默降级到 lite 接口；lite 仍 403 → 返回空数组而**不抛异常**；
- 业务层输出可操作中文说明，引导模型据知识库作答、不要重复调用：

```json
{
  "results": [],
  "resultCount": 0,
  "filteredOut": 0,
  "query": "维港泳赛事",
  "searchScope": "official",
  "metadata": { "engine": "duckduckgo", "rawCount": 0 },
  "error": "暂未从政府及权威官网检索到与“维港泳赛事”相关的内容，请依据知识库作答并注明“未能核实最新官方信息”。"
}
```

> 说明：样例 1、2 为封禁前真实抓取；封禁后用离线固定页面（样例 3）确定性复现过滤逻辑。
> 生产环境插件运行在 FastGPT plugin 容器，网络环境不同；本插件已内置「主接口→lite」两级降级、
> 12s 超时与空结果可操作文案，长期不稳定时仅需新增一个 `SearchProvider` 实现即可切换 Brave/SearXNG。

## 四、红线核对结论

1. 社交媒体（含官方账号、含子域）在 official 模式**零放行**：知乎、YouTube、Instagram 均被拒。
2. 营销平台（klook 等）在 official 模式拒绝，open 模式放行。
3. 未知域名**默认拒绝**（搜狐/百度/中介/个人博客全部丢弃），而非“不在黑名单就放行”。
4. 真实 URL 经 `uddg` 解码后再过滤，过滤对象是真实来源主机而非 `duckduckgo.com`。
5. SDK 封装层返回结果不含 `_debug`（已由集成测试断言 `'_debug' in returned === false`）。
