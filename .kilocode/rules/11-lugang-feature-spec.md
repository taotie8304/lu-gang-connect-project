# 功能规范模板

## 新功能开发流程
1. 在 `project-memory.md` 中记录功能目标
2. 技术方案确认后再动手（先设计后编码）
3. 完成后更新 `project-memory.md` 的已完成列表

## 功能文档格式
```
## 功能名称
- 目标：[解决什么问题]
- 方案：[技术实现概述]
- 文件：[涉及的关键文件]
- 测试：[测试通过情况]
```
