# 需求文档：香港政府开放数据 HTTP 工具集

## 简介

为鲁港通 AI 平台开发一套 HTTP 工具集，涵盖 15 个行业领域。每个工具专门获取对应行业的香港政府开放数据 API。基于官方 API 规范（https://data.gov.hk/en/help/api-spec）和实际测试经验，使用直接下载链接（data.one.gov.hk）而非不稳定的 v2/filter API。

## 术语表

- **HTTP 工具**：FastGPT 中的工具类型，通过 HTTP 请求调用外部 API
- **data.gov.hk**：香港政府开放数据平台
- **data.one.gov.hk**：香港政府静态文件服务器，提供稳定的直接下载链接
- **CKAN API**：data.gov.hk 使用的开源数据门户软件 API
- **直接下载链接**：指向静态文件的 URL（CSV/JSON/XML），无需额外 API 转换
- **行业工具**：针对特定行业领域的 HTTP 工具，获取该行业的政府开放数据

## 需求

### 需求 1：食品安全行业工具

**用户故事**：作为用户，我想查询食品安全相关数据，以便了解食物事故、食肆评级、进口食品等信息。

#### 验收标准

1. THE 工具 SHALL 调用食物安全中心（CFS）的开放数据 API
2. THE 工具 SHALL 使用直接下载链接（data.one.gov.hk）
3. THE 返回数据 SHALL 包含食物事故、食肆卫生评级、进口食品检测结果
4. WHEN API 返回 CSV 或 XML 格式 THEN THE 工具 SHALL 转换为 JSON
5. THE 工具 SHALL 提供清晰的中英文字段说明

### 需求 2：教育行业工具

**用户故事**：作为用户，我想查询教育相关数据，以便了解学校信息、教育统计等。

#### 验收标准

1. THE 工具 SHALL 调用教育局（EDB）的开放数据 API
2. THE 工具 SHALL 使用直接下载链接
3. THE 返回数据 SHALL 包含学校名单、学校地址、学校类型等信息
4. WHEN 数据格式为 CSV THEN THE 工具 SHALL 正确解析并转换为 JSON
5. THE 工具 SHALL 支持按学校类型或地区筛选（如果数据支持）

### 需求 3：交通行业工具

5. THE 工具 SHALL 提供交通快拍图像的 URL 链接

### 需求 4：气象行业工具

4. THE 工具 SHALL 支持查询不同时间段的天气数据
5. THE 数据 SHALL 实时更新（缓存时间不超过 15 分钟）

### 需求 16：通用功能 - 错误处理

**用户故事**：作为用户，我想在 API 调用失败时获得清晰的错误提示。

#### 验收标准

1. WHEN API 调用超时 THEN THE 工具 SHALL 返回超时错误信息
2. WHEN API 返回 404 THEN THE 工具 SHALL 提示数据源不可用
3. WHEN 数据格式错误 THEN THE 工具 SHALL 返回解析错误信息
4. THE 错误信息 SHALL 使用简体中文，清晰易懂
5. THE 工具 SHALL 记录错误日志供开发者排查

### 需求 17：通用功能 - 数据格式转换

**用户故事**：作为 AI，我想获得统一的 JSON 格式数据，以便更好地理解和处理。

#### 验收标准

1. THE 工具 SHALL 将所有 API 返回数据转换为 JSON 格式
2. WHEN API 返回 XML THEN THE 工具 SHALL 解析 XML 并转换为 JSON
3. WHEN API 返回 CSV THEN THE 工具 SHALL 解析 CSV 并转换为 JSON
4. THE 转换后的数据 SHALL 保持原始数据的完整性
5. THE JSON 数据 SHALL 使用清晰的字段名称（优先使用英文）

### 需求 18：通用功能 - 工具配置

**用户故事**：作为开发者，我想统一管理所有工具的配置，以便维护和更新。

#### 验收标准

1. THE 系统 SHALL 提供统一的工具配置文件（JSON 格式）
2. THE 配置文件 SHALL 包含每个工具的 API 端点、参数、描述
3. THE 配置文件 SHALL 符合 FastGPT HTTP 工具规范
4. WHEN API 端点变更 THEN 开发者 SHALL 只需更新配置文件
5. THE 配置文件 SHALL 包含工具的中英文名称和使用说明

### 需求 19：通用功能 - 测试和文档

**用户故事**：作为开发者，我想有完整的测试脚本和文档，以便验证工具功能。

#### 验收标准

1. THE 系统 SHALL 提供测试脚本验证所有 15 个行业工具
2. THE 测试脚本 SHALL 自动调用每个工具并验证返回数据
3. THE 系统 SHALL 提供每个工具的使用文档
4. THE 文档 SHALL 包含工具描述、参数说明、返回值示例
5. THE 文档 SHALL 说明数据来源和更新频率

### 需求 20：通用功能 - 性能优化

**用户故事**：作为用户，我想快速获得数据响应。

#### 验收标准

1. THE 工具 SHALL 在 10 秒内返回响应（正常情况）
2. THE 工具 SHALL 设置合理的超时时间（30 秒）
3. THE 工具 SHALL 使用 HTTP Keep-Alive 复用连接
4. THE 工具 SHALL 支持并发请求（如果需要查询多个数据源）
5. THE 系统 SHALL 记录每个工具的响应时间统计
