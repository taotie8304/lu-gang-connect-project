### Property 1: 图片格式支持
*For any* 有效的图片 URL（JPG、PNG、GIF、WebP 格式），图片渲染组件应该正确加载并显示图片
**Validates: Requirements 1.1, 1.3**

### Property 2: 图片加载失败处理
*For any* 无效的图片 URL，图片渲染组件应该显示占位符或错误提示，而不是崩溃或显示空白
**Validates: Requirements 1.2**

### Property 3: 思考模式样式隔离
*For any* 聊天回复内容，思考模式区域的背景色样式不应该影响最终答案区域的背景色
**Validates: Requirements 3.1, 3.2, 3.4**

### Property 4: 思考模式和最终答案的视觉区分
*For any* 包含思考模式的回复，思考模式区域应该使用灰色背景（#F7F8FA），最终答案区域应该使用白色或透明背景
**Validates: Requirements 3.1, 3.2**

### Property 5: 主题适配
*For any* 主题设置（浅色/深色），思考模式和最终答案的背景色应该自动调整以保持足够的对比度
**Validates: Requirements 3.5**

### Property 6: 表格正确渲染
*For any* 有效的 Markdown 表格，渲染器应该生成正确的 HTML 表格结构
**Validates: Requirements 4.1**

### Property 7: 表格换行控制
*For any* Markdown 表格，渲染后的 HTML 应该使用 CSS 属性（如 white-space、word-wrap）控制换行，而不应该包含 <br> 标签
**Validates: Requirements 4.2, 4.3**

### Property 8: 表格响应式显示
*For any* 宽度超过容器的表格，应该提供横向滚动功能，确保内容可访问
**Validates: Requirements 4.6**

### Property 9: 引用标记移除
*For any* 包含引用标记（如 [1], [2]）的文本，对于普通用户，渲染后的文本应该不包含这些标记
**Validates: Requirements 5.1, 5.5**

### Property 10: 引用标记移除后文本连贯性
*For any* 包含引用标记的文本，移除标记后，文本应该仍然连贯可读（没有多余的空格或标点）
**Validates: Requirements 5.6**

### Property 11: 角色权限控制
*For any* 用户角色（普通用户/管理员），引用内容的显示应该符合角色权限：普通用户不显示，管理员显示
**Validates: Requirements 5.1, 5.2, 5.3**

### Property 12: 引用数据保留
*For any* 包含引用的回复，即使不显示引用内容，引用数据应该仍然保留在数据结构中
**Validates: Requirements 5.4**

### Property 13: 移动端响应式布局
*For any* 屏幕宽度，聊天显示组件应该自动调整布局以适应屏幕尺寸
**Validates: Requirements 6.1, 6.2, 6.4**

## Error Handling

### 1. 图片加载错误

**错误场景**:
- 图片 URL 无效或不可访问
- 图片格式不支持
- 网络请求失败
- CORS 跨域问题

**处理策略**:
`	ypescript
// 图片加载失败时的降级处理
const handleImageError = (e: React.SyntheticEvent<HTMLImageElement>) => {
  // 1. 显示占位符图片
  e.currentTarget.src = '/images/placeholder.png';
  
  // 2. 或显示错误提示
  setImageError(true);
  
  // 3. 记录错误日志（用于调试）
  console.error('Image load failed:', src);
};
`

### 2. Markdown 渲染错误

**错误场景**:
- Markdown 语法错误
- 特殊字符导致渲染异常
- 表格格式不规范

**处理策略**:
`	ypescript
// 使用 Error Boundary 捕获渲染错误
class MarkdownErrorBoundary extends React.Component {
  componentDidCatch(error, errorInfo) {
    // 记录错误
    console.error('Markdown render error:', error);
    
    // 降级显示纯文本
    this.setState({ hasError: true });
  }
  
  render() {
    if (this.state.hasError) {
      return <Box whiteSpace="pre-wrap">{this.props.source}</Box>;
    }
    return this.props.children;
  }
}
`

### 3. 引用数据获取错误

**错误场景**:
- 引用 ID 无效
- 引用数据已被删除
- API 请求失败

**处理策略**:
`	ypescript
// 引用数据获取失败时的处理
const { data, error } = useRequest2(
  (id: string) => getQuoteData({ id, ...chatAuthData }),
  {
    manual: true,
    onError: (error) => {
      // 静默失败，不显示引用图标
      console.error('Quote data fetch failed:', error);
    }
  }
);

// 如果获取失败，不渲染引用组件
if (error) return null;
`

### 4. 样式冲突错误

**错误场景**:
- 思考模式样式污染最终答案
- 全局样式覆盖组件样式
- 主题切换导致样式异常

**处理策略**:
`	ypescript
// 使用 CSS Modules 或 styled-components 确保样式隔离
// 方案 1: CSS Modules
import styles from './AIResponseBox.module.scss';

<Box className={styles.thinkingMode}>
  {/* 思考模式内容 */}
</Box>
<Box className={styles.finalAnswer}>
  {/* 最终答案内容 */}
</Box>

// 方案 2: Chakra UI 的 sx prop（确保不使用全局样式）
<Box sx={{ bg: 'gray.50', p: 3 }}>
  {/* 思考模式内容 */}
</Box>
<Box sx={{ bg: 'transparent', p: 3 }}>
  {/* 最终答案内容 */}
</Box>
`

`	ypescript
// pages/api/image-proxy.ts
export default async function handler(req, res) {
  const { url } = req.query;
  const response = await fetch(url);
  const buffer = await response.arrayBuffer();
  res.setHeader('Content-Type', response.headers.get('content-type'));
  res.send(Buffer.from(buffer));
}
`

## Deployment Considerations

1. **向后兼容性**: 所有修改应该向后兼容，不影响现有功能
2. **性能影响**: 图片代理可能增加加载时间，需要监控性能指标
3. **缓存策略**: 图片代理应该实现缓存机制，减少重复请求
4. **错误监控**: 添加错误日志，监控图片加载失败率、Markdown 渲染错误等
